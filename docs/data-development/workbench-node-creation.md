# 数据开发节点创建

工作台新增入口采用分级菜单，当前一期提供：

```text
新建节点
├── 数据库
│   └── MySQL
└── 通用
    └── HTTP 节点

新建目录
```

节点创建弹窗只包含三个业务字段：

```text
类型
路径
名称
```

执行实现由节点插件负责，不在创建流程中额外选择“执行引擎”。MySQL 节点由 `MYSQL` Task Plugin 承接；JDBC 仅是插件内部连接实现，不作为用户可见节点类型。

路径使用数据开发资源树中的真实 Folder ID。选择 `/` 时创建到项目根目录，选择目录时将目录 ID 写入任务资源的 `parentId`。

界面使用 Ant Design 控件和 TailwindCSS，保持 Yak Ops 白底、高密度、浅边框与品牌色交互。
